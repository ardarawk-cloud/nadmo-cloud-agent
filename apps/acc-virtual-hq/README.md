# ACC Virtual HQ

Production frontend path for **ARDA CORE CORPORATION — KAI 3D Virtual HQ**.

Status: Phase A / frontend boundary established.

## Important

Do not copy the architecture of `apps/nadmo-virtual-hq` V1–V4 into this app.

That path remains prototype history only.

The production frontend will be built around:
- React
- React Three Fiber / Three.js
- persistent 3D ACC world
- embodied KAI entity
- agent selection
- goal / task overlays
- Decision Room
- owner approval
- realtime WebSocket events from `services/kai-core`

## Initial V5 world

- ACC Core
- KAI Core Chamber
- Owner Room
- Decision Room
- NADMO Studio
- Media & Nightlife
- Music & Entertainment
- Tech & Infra

Finance is added after the operational engine is stable.
