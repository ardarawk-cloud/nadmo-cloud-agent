# NADMO Scout Approval Gateway

Self-hosted replacement for the previous AppDeploy gateway.

Source of truth: GitHub.
Runtime: existing NADMO VPS behind agent.nadmo.id / Cloudflare.
Public path: https://agent.nadmo.id/scout-approval/

The visual UI, WhatsApp validation, approval flow, sales pipeline stages,
follow-up behavior, and status payloads are preserved.
